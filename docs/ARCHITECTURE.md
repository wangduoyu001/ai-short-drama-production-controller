# AI短剧导演系统架构 v0.7

## 目标

统一为单一导演生产系统：

输入剧本/创意 → 剧情结构 → 资产 → 分镜 → 生产任务 → 审核 → 输出。

## 核心模块

- core/workflow：工作流编排
- core/story：剧情与事件结构
- core/assets：人物、场景、道具资产
- core/storyboard：分镜管理
- agents：导演、编剧、资产、审核角色
- providers：模型和媒体服务适配层
- docs：开发规范和代码地图

## 原则

1. 单仓库单主线
2. 核心逻辑与具体模型解耦
3. 所有生产阶段可恢复
4. 人工审核保留在关键节点
